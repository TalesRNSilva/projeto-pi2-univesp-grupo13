# O que é 

Essa pasta serve para declarar objetos de modelos das entidades definidas na nossa arquitetura, para comunicação com o **banco de dados**.
Schemas de validação do front não entram aqui. 

Essa pasta só vai ser útil se algo como o SQLAlchemy for usado para administrar essa relação, ou pydantic for usado
para reproduzir o schema do banco de dados. Do contrário, essa pasta pode ser excluída.
