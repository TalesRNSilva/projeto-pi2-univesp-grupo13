# What is this

Para gerenciar a comunicação com o DB - inserção, remoção, atualização de dados -
a ideia é criar uma série de funções utilitárias nesta pasta para facilitar essa integração.

Os modelos de dados serão "burros" quanto à integração: servindo apenas para representar o schema da tabela,
sendo a inserção, por exemplo, sendo feita por uma função desse módulo.
